# Pizza Sales Analysis | SQL & Power BI

## Project Overview
This project analyses pizza sales data using MySQL and Power BI to understand sales performance, customer ordering patterns, and product demand.

## Tools Used
- MySQL
- Power BI
- DAX

## Key Analysis
- Calculated key performance indicators (KPIs), including total revenue, total orders, average order value, and total pizzas sold.
- Analysed daily and monthly order trends.
- Compared sales by pizza category and size.
- Identified top- and bottom-performing pizzas.
- Validated Power BI KPI calculations against SQL results.

- Created KPI measures using DAX.
